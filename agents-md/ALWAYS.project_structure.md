# project structure

## Separate folders for each main component

Use separate folders for each component:
- frontend/ for project frontend
- backend/ for project backend
- other folders for additional components (component.xyz/)

Check for AGENTS.md in each subproject folder.

# versioning files per component

- Include version.txt in each subsystem folder with format MAJOR.MINOR.RELEASE (e.g., "1.0.3")
- No linefeeds, version text only (numbers and periods)
- Auto-increment RELEASE (last part) when updating version.txt
