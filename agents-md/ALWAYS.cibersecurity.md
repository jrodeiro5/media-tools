# Security and Data Management

## General Security

- **Use environment variables** for sensitive data like credentials
- **Avoid hardcoded credentials** in configuration files or code
- **Use proper authentication and authorization** mechanisms
- **Implement proper data encryption** for sensitive data
- **Implement proper data access controls**
- **Implement proper data backup and recovery** procedures for persistent data stores
- **Design with privacy in mind** as much as possible
- **Passwords if saved should always be hashed and salted**

## OWASP Top 10

- Always design and code with OWASP Top 10 security vulnerabilities in mind, and implement proper countermeasures for each of them in frontend, backend and mobile apps
