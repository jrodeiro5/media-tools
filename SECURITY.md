# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Instead, report it privately via [GitHub Security Advisories](https://github.com/jrodeiro5/media-tools/security/advisories/new).

Include:
- A description of the vulnerability and its impact
- Steps to reproduce
- Affected version(s)

You should get a response within a few days. Confirmed vulnerabilities will be
patched and disclosed via a security advisory once a fix is available.

## Supported Versions

Only the latest release on `main` is supported.
